**mapSpainHist** is an R package with the municipal boundaries of Spain for each population
census between 1900 and 2001, provinces, judicial districts and historical electoral districts
built from them, and the census figures of every municipality (1842-2011).

> **Warning.** The boundaries of most historical municipalities are an approximate
> reconstruction: useful to represent municipal data graphically, to be used with caution for
> geographic variables such as area or distances.

```r
remotes::install_github("pauvallprat/mapSpainHist")
```
