# Problemes i suggeriments

Si detecteu algun error als mapes o a les dades (un municipi mal situat,
un límit incorrecte, un codi equivocat…) o voleu fer algun suggeriment,
us agrairé que me’l feu arribar. Les vostres aportacions ajuden a
millorar el paquet.

## Formulari

Ompliu el formulari i premeu **Envia**: s’obrirà el vostre programa de
correu amb el missatge preparat, adreçat a <pau.vall@ub.edu>. Només cal
que l’envieu.

Tipus Problema Suggeriment Consulta

Nom i afiliació (opcional)

Cens, municipi o unitat afectats (opcional)

Descripció

Envia

Si el formulari no obre el vostre programa de correu, podeu escriure
directament a <pau.vall@ub.edu>.
