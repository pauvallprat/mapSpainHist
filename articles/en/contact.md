# Problems and suggestions

If you find an error in the maps or in the data (a misplaced
municipality, a wrong boundary, a wrong code…) or want to make a
suggestion, please let me know. Your feedback helps improve the package.

## Form

Fill in the form and press **Send**: your e-mail program will open with
the message ready, addressed to <pau.vall@ub.edu>. You just need to send
it.

Type Problem Suggestion Question

Name and affiliation (optional)

Census, municipality or unit concerned (optional)

Description

Send

If the form does not open your e-mail program, you can write directly to
<pau.vall@ub.edu>.

## GitHub

If you have a GitHub account, you can also open an issue in the
repository. Issues are public and you can follow how they are solved:

- [Report a
  problem](https://github.com/pauvallprat/mapSpainHist/issues/new?template=problem.yml)
- [Make a
  suggestion](https://github.com/pauvallprat/mapSpainHist/issues/new?template=suggestion.yml)
- [See open issues](https://github.com/pauvallprat/mapSpainHist/issues)
