# Problemas y sugerencias

Si detecta algún error en los mapas o en los datos (un municipio mal
situado, un límite incorrecto, un código equivocado…) o quiere hacer
alguna sugerencia, le agradeceré que me la haga llegar. Sus aportaciones
ayudan a mejorar el paquete.

## Formulario

Rellene el formulario y pulse **Enviar**: se abrirá su programa de
correo con el mensaje preparado, dirigido a <pau.vall@ub.edu>. Solo
tiene que enviarlo.

Tipo Problema Sugerencia Consulta

Nombre y afiliación (opcional)

Censo, municipio o unidad afectados (opcional)

Descripción

Enviar

Si el formulario no abre su programa de correo, puede escribir
directamente a <pau.vall@ub.edu>.

## GitHub

Si tiene cuenta de GitHub, también puede abrir una incidencia (*issue*)
en el repositorio. Quedan registradas públicamente y se puede seguir
cómo se resuelven:

- [Notificar un
  problema](https://github.com/pauvallprat/mapSpainHist/issues/new?template=problem.yml)
- [Hacer una
  sugerencia](https://github.com/pauvallprat/mapSpainHist/issues/new?template=suggestion.yml)
- [Ver las incidencias
  abiertas](https://github.com/pauvallprat/mapSpainHist/issues)
